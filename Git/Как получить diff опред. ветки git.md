
Для **Azure Repos** используй обычный `git diff`. Допустим, PR направлен **из `feature/task` в `main`** и ещё не влит.

Сначала обнови данные с сервера:

``` C#
git fetch origin
```

Переключиться на опред. ветку

``` C#
git switch pr-123
```

Вывести все изменения PR в консоль:

``` C#
git --no-pager diff --no-color origin/main...origin/feature/task
```

Сохранить в файл:

``` C#
git diff --no-color --output=pr.diff origin/main...origin/feature/task
```

Замени `main` на целевую ветку PR, а `feature/task` — на исходную. **Три точки `...` важны**: сравнение идёт от общего предка веток до исходной ветки, показывая внесённые в ней изменения. Параметр `--output` сохраняет результат напрямую в файл. [Документация Git](https://git-scm.com/docs/git-diff)

**Если PR уже влит**, сравнение текущих веток может оказаться пустым — тогда нужно строить diff по коммитам, соответствующим этому PR.
